Supported equations & input rules

Operators

+ addition · - subtraction · * multiplication · / division · ^ power · ( ) grouping

Functions

sin(x), cos(x), tan(x), exp(x), log(x), sqrt(x), abs(x)

Constants

pi and e. Trigonometric functions use radians; log is the natural logarithm.

Input rules

  • Use x as the variable.
  • Write multiplication explicitly: 2*x, not 2x.
  • Function names are lowercase and require parentheses.
  • log(x) requires a positive argument; sqrt(x) requires a nonnegative argument.
  • Enter f(x); the solver interprets it as f(x) = 0.
