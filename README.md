# RootFinder — C++ / WebAssembly website

A responsive browser interface for solving `f(x) = 0` with Bisection, Newton–Raphson, and Secant. The numerical algorithms and expression parser are C++ compiled to WebAssembly with Emscripten. No calculation backend or npm packages are required.

## Project files

- `index.html` — page structure and supported-syntax guide
- `styles.css` — responsive visual design
- `app.js` — browser form, WebAssembly integration, iteration table, CSV export
- `solver.cpp` — expression parser and numerical methods
- `solver.js` and `solver.wasm` — generated by Emscripten (not included until you compile)

## 1. Install Emscripten

Install and activate the Emscripten SDK by following the official instructions: <https://emscripten.org/docs/getting_started/downloads.html>.

After installation, activate the SDK in your terminal. For example, from the `emsdk` directory:

**Windows (PowerShell or Command Prompt):**

```bat
emsdk\emsdk_env.bat
```

**macOS / Linux:**

```bash
source ./emsdk_env.sh
```

The path above is relative to the SDK directory; if you open a new terminal, activate the environment again. Verify the installation:

```bash
em++ --version
```

## 2. Compile the C++ solver to WebAssembly

Open a terminal in this project folder (the folder containing `solver.cpp`) and run:

```bash
em++ solver.cpp -std=c++17 -O2 -o solver.js \
  -s WASM=1 \
  -s MODULARIZE=1 \
  -s EXPORT_NAME=createSolverModule \
  -s EXPORTED_FUNCTIONS='["_solve","_free"]' \
  -s EXPORTED_RUNTIME_METHODS='["UTF8ToString","stringToNewUTF8"]' \
  -s ALLOW_MEMORY_GROWTH=1
```

This creates `solver.js` and `solver.wasm` in the current folder. On Windows Command Prompt, the line continuation character is `^` rather than `\`; you can also run the command on one line:

```bat
em++ solver.cpp -std=c++17 -O2 -o solver.js -s WASM=1 -s MODULARIZE=1 -s EXPORT_NAME=createSolverModule -s EXPORTED_FUNCTIONS="['_solve','_free']" -s EXPORTED_RUNTIME_METHODS="['UTF8ToString','stringToNewUTF8']" -s ALLOW_MEMORY_GROWTH=1
```

If your Emscripten shell has trouble parsing the quoted list options, use the POSIX command above from the Emscripten-provided Bash shell. Keep the generated `solver.js` and `solver.wasm` next to `index.html`.

## 3. Run the website locally

Browsers commonly block WebAssembly loading from a `file://` URL. Start a local HTTP server in this folder instead.

If Python 3 is installed:

```bash
python -m http.server 8000
```

Then open <http://localhost:8000> in your browser. Keep the terminal/server running while using the page. Alternatively, use VS Code's Live Server extension.

## 4. Deploy it

After compiling, publish these four files together to any static host:

- `index.html`
- `styles.css`
- `app.js`
- `solver.js` and `solver.wasm` (both generated files)

You can use GitHub Pages, Netlify, or another static host. Make sure `solver.wasm` is deployed beside `solver.js` and served with an appropriate WebAssembly MIME type (`application/wasm` is recommended).

## Supported equation syntax

- Variable: `x`
- Operators: `+`, `-`, `*`, `/`, `^`, and parentheses
- Functions: `sin(x)`, `cos(x)`, `tan(x)`, `exp(x)`, `log(x)`, `sqrt(x)`, `abs(x)`
- Constants: `pi`, `e`
- Trigonometric functions use radians; `log` means natural logarithm.
- Multiplication must be explicit: use `2*x`, not `2x`.
- Function names are lowercase. Enter the left-hand function only; the solver treats it as `f(x) = 0`.

## Numerical method inputs

- **Bisection:** requires lower bound `a < b` and opposite signs for `f(a)` and `f(b)` (unless an endpoint is already a root).
- **Newton–Raphson:** requires one initial guess. The derivative is approximated numerically using a central difference.
- **Secant:** requires two distinct initial guesses.
- Tolerance must be positive. Maximum iterations may be from 1 to 10,000.

The table records the values used in each iteration. Values are calculated at double precision and rounded only for display. Newton–Raphson and Secant may stop if the residual is within tolerance or if the step is sufficiently small and the residual is also reasonably small. Numerical methods can fail to converge for some equations or starting values; a reported approximate root is not a proof of uniqueness.

## Troubleshooting

- **“solver.js was not found”** — compile `solver.cpp` and ensure `solver.js` and `solver.wasm` are beside `index.html`.
- **Page does not load the solver** — use an HTTP server such as `python -m http.server`, not a `file://` URL.
- **Bisection reports no sign change** — choose an interval where endpoint function values have opposite signs.
- **Newton derivative is too close to zero / Secant denominator is too small** — try different initial guesses or another method.
- **Expression rejected** — use only listed functions and constants; include explicit multiplication such as `2*x`.
